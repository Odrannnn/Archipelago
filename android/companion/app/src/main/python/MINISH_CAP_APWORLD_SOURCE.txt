The Minish Cap APWorld v0.3.1
================================

Release: https://github.com/eternalcode0/Archipelago/releases/tag/v0.3.1
Asset: https://github.com/eternalcode0/Archipelago/releases/download/v0.3.1/tmc.apworld
Source commit: 0555bf272ac7ded6ed89b69c847fddd1e9c5f12c

The release asset is unpacked into worlds/tmc so Android does not depend on
Chaquopy's runtime ZIP-module importer. The embedded mobile copy removes only
this desktop-client import from tmc/__init__.py:

    from .client import MinishCapClient

Seed generation remains unchanged. Live emulator synchronization is provided
by the Android Kotlin GameAdapter and the custom mGBA libretro bridge instead
of the desktop BizHawk client.
